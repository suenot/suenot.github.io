# CCToggle: включать и выключать плагины и MCP Claude Code

[CCToggle](https://github.com/suenot/cctoggle) это небольшая утилита для временного изменения конфигурации Claude Code. Она может отключить настроенные плагины и MCP-серверы пользовательской области, записать сделанные изменения и затем восстановить это состояние.

Такой инструмент полезен, когда нужно проверить более узкий набор инструментов, изолировать проблему конфигурации или запустить задачу без необязательных интеграций. Влияние меньшего набора инструментов на конкретный workflow нужно измерять отдельно.

## Команды

Утилита дает slash-команду и CLI:

```bash
/cctoggle status
/cctoggle off
/cctoggle on
/cctoggle restore-backup
```

`status` показывает текущее состояние. `off` меняет состояние настроенных плагинов и user-scope MCP. `on` восстанавливает элементы, которые CCToggle записал как отключенные. `restore-backup` восстанавливает сохраненную копию конфигурации.

Можно работать выборочно:

```bash
cctoggle off --keep superpowers,caveman
cctoggle off graphify rtk
```

Первая форма оставляет указанные интеграции включенными, вторая нацелена на перечисленные интеграции. Перед применением проверьте показанный план, особенно если конфигурацией пользуются несколько человек.

## Что меняет утилита

Для плагинов CCToggle обновляет настройки включенных плагинов. Для MCP пользовательской области она меняет определения в пользовательской конфигурации Claude Code и хранит локальную запись о своем изменении. Восстановление намеренно уже, чем команда "включить все": оно должно отменить именно то, что выключила CCToggle.

Это важно, если плагин или сервер был отключен по другой причине. Инструмент управления состоянием не должен молча менять выбор, который он не делал.

## Как применяются изменения

Плагины и MCP не обязательно применяют конфигурацию одновременно. Перезагрузите плагины, если Claude Code поддерживает это в текущей сессии. Для MCP-конфигурации начните новую сессию Claude Code, когда текущий процесс уже подключил сервер. Очистка или сжатие диалога не заменяет перезапуск процесса, который держит MCP-соединение.

Серверы, переданные динамически при запуске, а не через пользовательскую конфигурацию, не управляются этим механизмом. Чтобы изменить их, измените команду запуска и создайте новый процесс.

## Установка и восстановление

В репозитории описана установка через `install.sh`:

```bash
git clone https://github.com/suenot/cctoggle.git ~/projects/claude
~/projects/claude/install.sh
```

Перед использованием в рабочей конфигурации изучите установщик и создайте резервную копию настроек. CCToggle также хранит копии конфигурации для своей команды восстановления. Считайте их чувствительными, если в MCP-определениях есть учетные данные, и не добавляйте их в репозиторий.

Утилита установлена как user-команда, а не плагин, поэтому путь восстановления остается доступным после отключения плагинов. Актуальные команды и детали конфигурации смотрите в [репозитории CCToggle](https://github.com/suenot/cctoggle).
