# GonkaGate как OpenAI-совместимый провайдер моделей

[GonkaGate](https://gonkagate.com/en) дает OpenAI-совместимый API для моделей, доступных через сеть Gonka. Поэтому API можно подключать к инструментам, которые поддерживают формат OpenAI API, включая терминальных агентов с пользовательскими провайдерами.

Цены, стартовые кредиты, список моделей и лимиты меняются. Перед запуском нагрузки проверяйте актуальную [страницу цен GonkaGate](https://gonkagate.com/en/pricing), баланс аккаунта и список моделей.

## Создайте ключ и проверьте API

Создайте API-ключ в панели провайдера и храните его в переменной окружения или менеджере секретов. Не добавляйте ключ в репозиторий, историю командной оболочки или промпт.

API использует bearer-токен и запрос chat completions в формате OpenAI:

```bash
curl https://api.gonkagate.com/v1/chat/completions \
  -H "Authorization: Bearer $GONKAGATE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_CURRENT_MODEL_ID",
    "messages": [{"role": "user", "content": "Reply with exactly: GonkaGate ok"}]
  }'
```

Замените `YOUR_CURRENT_MODEL_ID` на ID модели из текущего ответа `GET /v1/models`. Не полагайтесь на имя модели из старого конфига. При замере задержки, скорости или качества записывайте модель и время проверки.

## Настройте терминального агента

OpenCode умеет работать с пользовательским OpenAI-совместимым провайдером. Формат конфигурации может меняться между версиями OpenCode, но важны имя провайдера, base URL, API-ключ и ID модели. Пример конфигурации:

```json
{
  "provider": {
    "gonkagate": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "GonkaGate",
      "options": { "baseURL": "https://api.gonkagate.com/v1" }
    }
  }
}
```

Если есть установщик провайдера, используйте его инструкцию, затем изучите получившийся конфиг и запустите диагностику самого агента. Перед долгой задачей на код или пакетной обработкой проверьте небольшой реальный сценарий.

Другие агенты, которые принимают пользовательский OpenAI-совместимый base URL, используют ту же схему. Если инструмент поддерживает переменные окружения или хранилище секретов, не храните учетные данные в файлах конфигурации.

## Схемы инструментов и эксплуатационная проверка

API-совместимость не делает все схемы инструментов переносимыми. Бэкенд модели может поддерживать более узкий набор JSON Schema или другой диалект регулярных выражений, чем клиент, создавший схему. Если запрос инструмента не проходит валидацию, упростите схему до поддерживаемого набора и проверьте ее отдельно.

На типичных задачах измеряйте ошибки запросов, повторы, расход токенов, задержку и качество результата. Низкая заявленная цена сама по себе не определяет итоговую стоимость, особенно при ошибках, длинных контекстах и повторных вызовах.

Рабочий процесс прост: подтвердите текущий список моделей и условия, держите ключ вне системы контроля версий, сделайте небольшой API-запрос и затем проверьте конфигурацию агента на реальной задаче. Выбор провайдера требует наблюдения, а не разового сравнения цен.
